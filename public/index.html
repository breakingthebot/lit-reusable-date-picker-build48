⌨️ Keyboard Shortcuts Guide (WCAG 2.1 AA):
  • ArrowLeft / ArrowRight: Navigate previous / next day
  • ArrowUp / ArrowDown: Navigate previous / next week (-7d / +7d)
  • Home / End: Jump to first / last day of rendered month
  • PageUp / PageDown: Jump to previous / next month
  • Enter / Space: Select focused calendar date
  • Escape: Close open calendar dropdown
